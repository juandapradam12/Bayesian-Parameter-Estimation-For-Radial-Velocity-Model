\section*{Overview}
Observed galactic rotation curves are modelled as the circular velocity arising from a
Plummer bulge, a Miyamoto--Nagai disk, and an extended halo. Scaled masses
\(M_b\), \(M_d\) and \(M_h\) are inferred with Metropolis--Hastings MCMC.

The figure below is produced by the corrected legacy C pipeline in this directory.
For diagnostics, multi-chain \(\hat{R}\), and the modern Python package, see the
repository root README and \texttt{docs/}.
